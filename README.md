Pidilite Industries DCF Valuation

This project estimates the intrinsic equity value of Pidilite Industries using a Free Cash Flow to Firm (FCFF) discounted cash flow model.

Project file

Pidilite_DCF_Model_GitHub_Final.xlsx — complete Excel model containing historical financials, assumptions, forecasts, valuation and checks.

Model scope

Historical consolidated financial statements from FY2022 to FY2026

Five-year operating forecast from FY2027 to FY2031

Revenue, EBITDA, depreciation, tax, capital expenditure and working-capital assumptions

FCFF calculation using NOPAT + D&A - Capex - Change in NWC

Bottom-up WACC calculation

Perpetuity-growth terminal value

Enterprise-value-to-equity-value bridge

Implied value per share and WACC/terminal-growth sensitivity analysis

Source references and financial-statement reconciliation checks

Base-case result

The model produces an implied value of approximately ₹414.53 per share. The sensitivity table produces values ranging from approximately ₹308 to ₹682 per share across the selected WACC and terminal-growth assumptions.

The market price shown in the workbook is a dated reference input and is not required for the intrinsic-value calculation, except for the largely immaterial debt/equity weighting in WACC.

How to use the model

Download and open the Excel workbook.

Review the Summary and DCF tabs for the headline result.

Change the pale-yellow cells on the Assumptions tab to test alternative views.

Review the Forecast tab to see how the assumptions flow into FCFF.

Use the sensitivity table on the DCF tab to assess valuation uncertainty.
